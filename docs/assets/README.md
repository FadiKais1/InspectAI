# Qualitative assets

This folder is intentionally **without MVTec photographs**.

MVTec AD is a third-party research dataset. Redistributing original images,
or overlays that still show those images, would copy licensed dataset
content into git.

Generate panels locally instead:

- `outputs/experiments/m7_transistor_dinov3/analysis/`
- `python scripts/inspect_image.py` → `outputs/demo/`

See [m7_transistor_dinov3.md](../m7_transistor_dinov3.md) for the locked
qualitative write-up.
